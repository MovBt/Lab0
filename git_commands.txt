git init - Создаёт новый локальный репозиторий в текущей папке.
git clone - Копирует существующий удалённый репозиторий на ваш компьютер.
git status - Показывает текущее состояние файлов (изменённые, удалённые, подготовленные).
git add - Добавляет изменённые файлы в индекс для подготовки к коммиту.
git commit - Фиксирует подготовленные изменения и сохраняет их в историю.
git push - Отправляет ваши локальные коммиты в удалённый репозиторий.
git pull - Загружает последние изменения с сервера и объединяет их с вашим кодом.
git branch - Показывает список существующих веток или создаёт новую ветку.
git checkout - Переключает рабочее окружение на другую ветку.
git log - Отображает историю всех сделанных коммитов с их авторами и датами.
git diff - Показывает разницу между файлами.
